Privacy Policy

Maybeland HQ · Last updated 2 October 2026

Who uses this app

Maybeland HQ is a private tool used only by the owner of the Maybeland Stories YouTube channel. It is not offered to the public.

What data it accesses

With the owner's permission, through Google's sign-in, the app reads the channel's own statistics using the YouTube Analytics API, the YouTube Reporting API and the YouTube Data API, with read-only access:

  • per-video views, watch time, average percentage viewed and subscriber changes
  • thumbnail impressions and click-through rate
  • the channel's subscriber count

It does not access email, contacts, files, payment details or any other Google data, and it cannot upload, edit or delete anything.

How the data is used and stored

  • The numbers are saved on the owner's own computer and in the owner's private dashboard, only to track how the channel's videos perform.
  • The data is never sold, shared with third parties, or used for advertising.
  • The sign-in token is stored only on the owner's computer.

Google API Services User Data Policy

Maybeland HQ's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube data is accessed under the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the saved files removes all stored data.

Contact

Questions can be sent through the contact details on the Maybeland Stories channel page.
